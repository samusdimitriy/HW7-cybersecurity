# Лабораторна робота: SCA‑аналіз npm‑пакетів (jsonwebtoken 8.5.1, event-stream 3.3.6, minimist 0.2.0)

## 1. Загальні відомості

- **Пакети та версії**:
  - **jsonwebtoken 8.5.1** — бібліотека для створення та перевірки JWT.
  - **event-stream 3.3.6** — пакет для роботи з потоками Node.js (компрометована версія).
  - **minimist 0.2.0** — розбір аргументів командного рядка.
- **Репозиторії**:
  - https://github.com/auth0/node-jsonwebtoken
  - https://github.com/dominictarr/event-stream
  - https://github.com/substack/minimist
- **Дата аналізу**: 3 січня 2026 р.
- **Інструменти**: osv-scanner 2.3.1, syft 1.39.0, grype 0.104.3.

## 2. Попередній аналіз (Socket.dev)

- **jsonwebtoken 8.5.1**: Supply Chain Security 99, Quality 100, Maintenance 89, License 100, Vulnerability 82. Є попередження про CVE високого/середнього рівня.
- **event-stream 3.3.6**: сторінка Socket.dev відсутня (Page Not Found), що узгоджується з вилученням версії після інциденту зі шкідливим кодом.
- **minimist 0.2.0**: Supply Chain 100, Quality 96, Maintenance 83, License 100, Vulnerability 25. Низька оцінка уразливостей через відомі CVE.

## 3. Граф залежностей (deps.dev)

- **jsonwebtoken 8.5.1**: 10 прямих залежностей (jws, lodash.includes, lodash.isboolean, lodash.isinteger, lodash.isnumber, lodash.isplainobject, lodash.isstring, lodash.once, ms, semver) і 4 транзитивні (buffer-equal-constant-time, ecdsa-sig-formatter, jwa, safe-buffer).
- **event-stream 3.3.6**: версію не знайдено (deps.dev пропонує 4.0.1).
- **minimist 0.2.0**: залежності відсутні.

## 4. Оцінка безпекової гігієни (OpenSSF Scorecard)

- **jsonwebtoken**: 5.7/10. Немає Token Permissions, відсутні pinned dependencies та fuzzing, слабка підтримка.
- **event-stream**: 2.5/10. Проєкт не підтримується, немає Branch Protection та Code Review.
- **minimist**: 4.6/10. Низька підтримка, відсутні оновлення залежностей та захист гілок.

## 9. Висновки та рекомендації

- **jsonwebtoken 8.5.1** містить кілька уразливостей; рекомендовано оновлення до **9.0.0** або новішої версії.
- **event-stream 3.3.6** компрометований і вилучений з реєстру; використовувати пакет не можна, потрібна заміна на підтримувану альтернативу.
- **minimist 0.2.0** містить критичні уразливості; рекомендовано перейти мінімум на **0.2.4** або **1.2.6+**.
- Варто інтегрувати **OSV-Scanner**, **Syft** і **Grype** у CI/CD для регулярного SCA та автоматичного контролю SBOM.
- Необхідно відстежувати CVE та EPSS, пріоритезувати оновлення й обмежувати використання непідтримуваних залежностей.

### Скріншоти для event-stream 3.3.6 (підтвердження на порталах)

- **Наявність пакета на основних порталах**: на Socket.dev сторінка версії 3.3.6 відсутня — сервіс повідомляє, що пакунку з такою версією не існує. На deps.dev аналогічно відображається повідомлення «Version Not Found» для цієї версії. Це підтверджує, що пакет був вилучений з реєстру npm через інцидент зі шкідливим кодом.
- **OpenSSF Scorecard**: звіт Scorecard для репозиторію github.com/dominictarr/event-stream показує дуже низький сумарний бал (≈2,5) й численні провалені перевірки (відсутність ревʼю коду, підписаних релізів, оновлення залежностей тощо). Це свідчить про вкрай низький рівень безпеки й підтримки.
- **OSV (пошук у базі уразливостей)**: запит event-stream повертає єдиний релевантний запис GHSA‑mh6f‑8j2x‑4483 (event-stream / flatmap-stream malicious code injection) з критичним рівнем (CVSS 9.8). У ній йдеться про вбудований бекдор, що давав змогу викрадати біткоїн‑гаманці; виправленням було повне вилучення скомпрометованої версії. Жодних інших CVE для event-stream у базі OSV немає.
- **CVE Details та MITRE**: пошук на cvedetails.com за ключем «event-stream» не дав результатів, оскільки бекдор не був оформлений як окремий CVE. Відомий інцидент відстежується через GitHub Advisory (GHSA‑mh6f‑8j2x‑4483) і описується в інших джерелах як CVE‑2018‑1000659 для flatmap-stream. Це підтверджує, що CVE для самого event-stream відсутні, але використання пакета небезпечне.
